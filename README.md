# 雲仙花苑 公式サイト

長崎・雲仙の本榊農園「雲仙花苑」の公式サイトです。
HTMLと画像はすべて同じ階層(フラット構造)に配置しています。

## ページ
- index.html … トップページ
- nursery.html … 苗の販売
- quality.html … 品質へのこだわり
- care-print.html / nursery-print.html … 印刷用

## GitHub Pages 公開手順
1. Settings → Pages → Source: main branch / (root)
2. 数分後 https://<ユーザー名>.github.io/<リポジトリ名>/ で公開
