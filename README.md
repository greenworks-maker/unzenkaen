# 雲仙花苑 公式サイト

長崎県・雲仙の麓で本榊を育てる「雲仙花苑」の公式Webサイトのソースコードです。

## ページ構成

- `index.html` — トップページ
- `nursery.html` — 苗の販売
- `quality.html` — 品質へのこだわり詳細
- `care-print.html` — お手入れガイド(印刷用)
- `nursery-print.html` — 苗販売(印刷用)
- `images/` — 写真・ロゴ

## デプロイ方法

### GitHub Pages

1. Settings → Pages → Source: `main` branch / `/(root)`
2. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### その他

- Cloudflare Pages、Netlify、Vercel、Xserver等にもそのままアップロードできます
